Branches, merging, and GitHub Pages

This static lab page is published from the main branch after a feature branch was created and merged.

Lab workflow

  1. Create a branch: git switch -c feature/lab-page
  2. Commit the page: git add . && git commit -m "Add lab page"
  3. Merge it: git switch main && git merge --no-ff feature/lab-page
  4. Publish the main branch with GitHub Pages.
